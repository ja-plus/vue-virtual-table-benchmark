可用性对比

判定口径：列固定 = 是否支持左右固定列（TDesign 左右固定互斥计部分）； 行高控制 = 是否原生支持设置行高（经 CSS 压缩实现计部分，如 surely-vue / naive-ui / tdesign / primevue）； 横向虚拟列表 = 列级虚拟化，横向滚动只渲染可见列（整行渲染、仅容器横向滚动计不支持）； 宽度控制 = 容器宽度自适应铺满（element TableV2 需 ResizeObserver 动态控制计部分）。 ✓ 支持　△ 部分　✕ 不支持。

指标明细

绿色 = 该列最优，红色 = 该列最差。渲染耗时 = 点击 Tab → DOM 稳定（含异步 chunk 加载）； 无白屏速度 = 内容跟随驱动下表格保持视口内容完整所能达到的滚动速度，是滚动性能的核心指标； 掉帧数 = 帧耗时 > 33.4ms 的帧数量；scroll = 无白屏内容跟随驱动，wheel = 合成滚轮事件（canvas 类表格）； 白屏率 = 滚动中视口内容缺失帧占比（内容跟随时序下应接近 0，非零值供校验）； 实际滚动(px) 为会话中达到的最大 scrollTop，wheel 方式记为 -1。
