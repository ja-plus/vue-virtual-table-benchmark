功能丰富度对比

判定口径：列固定 = 是否支持左右固定列（TDesign 左右固定互斥计部分）；
行高控制 = 是否原生支持设置行高（经 CSS 压缩实现计部分，如 surely-vue / naive-ui / tdesign / primevue）；
横向虚拟列表 = 列级虚拟化，横向滚动只渲染可见列（整行渲染、仅容器横向滚动计不支持；库原生支持但当前版本缺陷未启用计部分支持，如 naive-ui 2.44.1 的 virtual-scroll-x 固定列错位）；
宽度控制 = 容器宽度自适应铺满（element TableV2 需 ResizeObserver 动态控制计部分）；
列筛选 = 列头内置筛选器，无需手动实现；列排序 = 列头内置排序触发；
单元格编辑 = 内置行内编辑能力；导出 = 内置导出 CSV/Excel 能力；
树形/展开行 = 树形数据或行展开详细视图（仅展开行计部分，如 naive-ui / element-plus 等）；
合并单元格 = 内置单元格合并 API（rowspan/colspan）；表头分组 = 多级列头分组；
区域选择 = 鼠标拖拽或 Shift+click 选择多单元格区域。
✓ 支持　△ 部分　✕ 不支持。

易用性主观评分

易用性为作者在接入本项目（10000 行 × 40 列、左右固定列、横纵虚拟滚动）过程中的主观评分（5 分制，0.5 分档）， 评估维度：配置复杂度 / 文档质量 / 类型提示与 API 设计 / 开箱即用程度。

指标明细

绿色 = 该列最优，红色 = 该列最差。
渲染耗时 = 点击 Tab → DOM 稳定（含异步 chunk 加载）；
DOM 节点数 = 表格渲染稳定时的 DOM 元素总数，越低说明虚拟化越彻底；
无白屏速度 = 内容跟随驱动下表格保持视口内容完整所能达到的滚动速度，是滚动性能的核心指标；
掉帧数 = 帧耗时 > 33.4ms 的帧数量；
scroll = 无白屏内容跟随驱动，wheel = 合成滚轮事件（canvas 渲染表格如 VTable、canvas-vue-table）；
实际滚动(px) 为会话中达到的最大 scrollTop，wheel 方式记为 0。
